# PhotoHunt — охота за цветом

Мобильное веб-приложение: каждый день получаешь один цвет — и должен **сфотографировать** три вещи этого цвета. Из находок собирается красивая открытка, а из дней — личный журнал и стрик.

Галерея не принимается принципиально: только живая камера.

**Живая версия:** https://wakkich.github.io/PhotoHunt/

## Что умеет

- **Цвет дня** — 42 названия («Матча-лате», «Синий кит», «Пион»), детерминированно по дате.
- **Живая камера** — полноэкранный вьюер, рамка-наводка, вспышка, переворот камеры, таймаут и понятные ошибки доступа.
- **Анализ палитры** — доминирующие цвета кадра считаются локально на `<canvas>`, без сервера и AI. Показывает «% попадания» в цвет дня.
- **Открытка** — 1080×1350, генерируется на клиенте, скачивается или шарится через Web Share API.
- **Журнал** — контакт-лист дней, стрик, лучшая серия.
- **PWA** — ставится на домашний экран, манифест создаётся на лету.

## Запуск

Ни сборки, ни зависимостей — один `index.html`.

```bash
# локально
start index.html        # Windows
open index.html         # macOS
```

Для камеры на телефоне нужен HTTPS. Самый быстрый бесплатный вариант:

1. Открой [Netlify Drop](https://app.netlify.com/drop) и перетащи папку.
2. Или включи GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Стек

- Ванильный HTML/CSS/JS, без фреймворков и сборки.
- Google Fonts: Manrope + Playfair Display.
- Google Material Symbols Rounded для иконок.
- `getUserMedia` + `<canvas>` + `localStorage` + Web Share API.

## Приватность

Фотографии не покидают устройство: они сжимаются до 300×300 и лежат в `localStorage` браузера. Сервера нет.
